غلاف تطبيق «SkillBridge International School»
================================
الملفات:
  index.html            صفحة الغلاف (لا تعدّلها)
  config.js             الإعدادات: اسم المدرسة ورابط الواجهة (الملف الوحيد الذي تعدّله)
  manifest.webmanifest  اسم التطبيق والأيقونات ولون الشاشة
  sw.js                 يجعل التطبيق يفتح فورًا (يخزّن الغلاف فقط، لا بيانات المدرسة)
  icons/                الأيقونات (حرف «ج» مؤقتة، استبدلها بالشعار)

1) اضبط الرابط
   افتح config.js وضع رابط تطبيق الويب (ينتهي بـ /exec) في APP_URL.

2) استبدل الأيقونات بشعار المدرسة (PNG، خلفية غير شفافة، الشعار في الوسط بهوامش)
   icons/icon-192.png          192×192
   icons/icon-512.png          512×512
   icons/icon-maskable-512.png 512×512 (الشعار ضمن الثلثين الأوسطين من الصورة)
   icons/apple-touch-icon.png  180×180
   احتفظ بالأسماء نفسها.

3) الرفع على GitHub Pages (مجاني، بحساب المدرسة)
   - أنشئ مستودعًا عامًا باسم مثل school-app.
   - ارفع كل محتويات هذا المجلد إلى جذر المستودع.
   - Settings ← Pages ← Branch: main، المجلد: /(root) ← Save.
   - بعد دقائق يظهر الرابط: https://اسم-الحساب.github.io/school-app/

4) التثبيت
   - Android (Chrome): افتح الرابط ← ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
   - iPhone (Safari): مشاركة ← «إضافة إلى الشاشة الرئيسية».
   - الحاسوب (Chrome أو Edge): أيقونة التثبيت في شريط العنوان، أو القائمة ← تثبيت.

نمط التشغيل MODE في config.js:
   redirect (الافتراضي): يفتح الغلاف الواجهة مباشرة. الأضمن مع تسجيل الدخول بحساب Google.
   frame: يضع الواجهة داخل الغلاف. لا ينفع مع الواجهة المنشورة بتنفيذ «كالمستخدم»،
          لأن Google لا تسمح بتسجيل الدخول داخل إطار.
